## 1. What makes a test positive or negative?
A valid input will give a positive test while a invalid input will give a negative test
## 2. Why can a negative test pass?
Because the end user is testing for a invalid input and wants to see if the system will reject it, if the system rejects the purposeful invalid input it is a pass on the negative test
## 3. How did equivalence partitioning help you select data?

## 4. What did boundary testing help you investigate?
Helped us test if the systems could handle input values near to and on the minimum and maximum value.
