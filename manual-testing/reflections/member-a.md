What makes a test positive or negative?

A positive test uses valid inputs to check whether the system works as expected, while a negative test uses invalid inputs to check whether the system handles them correctly.

Why can a negative test pass?

A negative test can pass because the system correctly rejects the invalid input. For example, when entering an age of 17, the system should reject it. If it does, the test passes.

How did equivalence partitioning help you select data?

Equivalence partitioning helped us divide the inputs into different groups based on whether they are valid or invalid. Instead of testing every possible age, we could select one representative value from each group, such as 10, 30 and 90.

What did boundary testing help you investigate?

Boundary testing helped us check whether the system correctly handles values near the minimum and maximum allowed ages. For example, testing ages 17, 18, 80 and 81 helped us identify whether the system accepts and rejects values at the correct boundaries.

What did you choose to test during the open-ended activity, and why?

I chose to test whether entering an incorrect username with a correct password would cause the login to fail. I wanted to ensure that the system checks both the username and password instead of just the password, especially if multiple accounts happen to share the same password.

Did your observations lead to follow-up tests?

My test showed that entering an incorrect username with a correct password resulted in a failed login, which was the expected outcome. I did not conduct any further tests as the system behaved as expected.
